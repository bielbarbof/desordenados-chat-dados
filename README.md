# DSO Chat v0.3.2

Chat e rolador Tech Noir DSO para Owlbear Rodeo.

Esta atualização preserva integralmente a interface da v0.3.1 e adiciona a ponte com o **DSO System**: quando um jogador controla um protagonista, a aba **+ TESTE** recebe automaticamente os atributos e perícias daquela ficha.

O DSO Chat continua funcionando sozinho; sem o DSO System instalado, a Ficha Rápida permanece configurável normalmente.
